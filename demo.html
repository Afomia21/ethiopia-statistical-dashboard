Ethiopian Statistical Service - Demo Page

This is a pretend website page

This file is just a demo to show what the small chat widget looks like once it is added to a real website. It is NOT the real ess.gov.et site - it is only here so you can preview the widget yourself before handing it off.

Look at the bottom-right corner of this page. You should see a small round blue button with a 🤖 face on it. Click it to open the small chat window.

On the real website, this exact same small button and chat window would appear on every page, floating in the corner, no matter how much content is on the page around it.
